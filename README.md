### About Me

I focus on building web interfaces with JavaScript, TypeScript, and React. My projects include a multilingual online store, a customer management dashboard, and interactive shopping demos. I also work with Node.js, Express, and MongoDB on the backend.

- 🛒 I develop product catalogs, search, filters, shopping carts, and wishlists.
- 🔌 I connect interfaces to REST APIs and manage server and application state.
- 🌍 I build multilingual interfaces with support for Uzbek, Russian, and English.
- 🧪 I use Vitest, Playwright, and axe to test functionality and accessibility.
